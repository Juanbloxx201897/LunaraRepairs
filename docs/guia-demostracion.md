# Guía de demostración

1. Abre el panel y revisa las métricas.
2. Consulta las órdenes en diferentes estados.
3. Crea un cliente y un dispositivo.
4. Crea una orden vinculada al cliente, dispositivo y técnico.
5. Registra diagnóstico y presupuesto.
6. Aprueba o rechaza la cotización desde el flujo de estados.
7. Avanza una orden aprobada a reparación, pruebas, lista y entregada.
8. Abre Swagger para demostrar la API REST.

La interfaz de perfiles es demostrativa. La autorización real de clientes y técnicos debe implementarse antes de usar datos reales.
