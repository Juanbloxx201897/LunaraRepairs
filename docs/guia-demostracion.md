# Guía de demostración

1. Abre el panel y revisa las métricas y el gráfico de ventas por mes.
2. Consulta las órdenes en diferentes estados.
3. Crea un cliente y un dispositivo.
4. Crea una orden vinculada al cliente, dispositivo y técnico.
5. Abre **Guía de precios de mano de obra** como administrador, busca las tarifas de prueba por equipo, marca o trabajo y valida las que correspondan a tus precios reales quitándoles la marca de prueba. Puedes editar o desactivar las demás.
6. Inicia sesión como técnico, consulta la guía con el buscador y elige una tarifa para el equipo de la orden. El importe sugerido se puede ajustar antes de enviar el presupuesto; agrega también los repuestos necesarios.
7. Guarda el diagnóstico y comprueba el envío del presupuesto al correo del cliente (requiere Gmail SMTP configurado).
8. Inicia sesión como cliente, abre el detalle de la orden y revisa el problema reportado, diagnóstico, trabajo realizado y observaciones del seguimiento; luego aprueba o rechaza el presupuesto pendiente.
9. Avanza una orden aprobada a reparación, pruebas, lista y entregada.
10. Abre Swagger para demostrar la API REST.

El catálogo de marcas se sugiere a partir de los dispositivos registrados; también se pueden escribir marcas nuevas. Configura Gmail con una clave de aplicación para probar el envío real de correo.

La base nueva recibe tarifas de demostración para celulares, portátiles, tabletas, consolas, computadores y otros equipos. Están marcadas **PRUEBA** y son importes referenciales, no una lista de precios de mercado. El administrador debe validar o ajustar cada tarifa antes de usarla con un cliente. El buscador filtra por equipo, marca, trabajo o precio.
